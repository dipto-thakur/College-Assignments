# Assignment 08 — Absolute and Cumulative Frequency Diagrams

**Date:** 06/06/26

## Problem

Draw suitable diagrams to represent both the absolute and cumulative
frequencies for this family size distribution across 100 families:

| Family Size | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|---|---|---|---|
| Frequency | 26 | 21 | 17 | 12 | 9 | 3 | 2 | 2 | 1 |

## How it works

Two separate charts, since absolute and cumulative frequency are best
shown differently:

- **Absolute frequency** (how many families have exactly this size) is
  shown as a **bar chart**, `plt.bar()`, one bar per family size, height
  equal to that size's raw frequency. A bar chart suits this since each
  family size is a distinct, separate category, there's nothing
  "between" a family of 4 and a family of 5.
- **Cumulative frequency** (how many families have this size *or
  smaller*) is shown as a **line chart** with markers, `plt.plot()`.
  The values come from `np.cumsum(frequencies)`, which runs a running
  total across the frequency list, each point on the line is the sum of
  every frequency up to and including that family size. A line suits
  this better than a bar chart, since cumulative frequency is inherently
  a running, accumulating quantity, and by the last point it should
  reach the total number of families (100 here), a good sanity check
  that the math is right.

### A note on running this outside a notebook

The original code only calls `plt.show()`, which pops up an interactive
window, fine in a Jupyter notebook or a normal desktop Python session,
but it won't produce a visible result when run in a plain terminal
without a display attached. This version adds a `plt.savefig(...)` call
right before each `plt.show()`, so running the script also writes
`absolute_frequency.png` and `cumulative_frequency.png` to disk
regardless of whether a display is available. `plt.show()` is still
there too, so it behaves exactly as before in any environment that does
have a display.

## Run it

```
pip install matplotlib numpy
python frequency_diagrams.py
```

This produces two files in the same folder:
- `absolute_frequency.png`
- `cumulative_frequency.png`

## Output

Both charts were generated by actually running this script.

**Absolute Frequency Distribution** — a bar chart peaking sharply at
family size 2 (26 families) and tapering off toward size 10 (just 1
family), showing most families in this dataset are on the smaller side.

**Cumulative Frequency Distribution** — a rising line starting at 26
(family size 2) and climbing to 100 by family size 10, since every
family in the dataset has a size of 10 or less, the cumulative total by
the last point always equals the full sample size.
