Main Heading - H1

The h1 tag is used for the main title of a page. Every page should really have only one h1 because it tells both the browser and search engines what the page is mainly about. It's usually the biggest and boldest text on the page too.

Sub Heading - H2

H2 is used for major sections inside a page. If h1 is the book title, h2 is like a chapter title. It helps break a long page into readable chunks and also helps with SEO since search engines look at h2 tags to understand the structure of the content.

Smaller Heading - H3

H3 is used for smaller subsections under an h2. Think of it as a sub-topic inside a chapter. Using headings in the right order (h1 then h2 then h3) keeps the document organized and easy to scan for anyone reading it.
