# HTML & CSS Assignments

This repo has 16 small assignments, mostly HTML with CSS layered in as the assignments
progress. Each html file has the original assignment question pasted in as a comment right
at the top, so you can open any file and see what it was asking for before looking at the code.

Just open any .html file directly in a browser, nothing needs to be built or installed.
Assignment 8 depends on style8.css sitting in the same folder (it's linked as an external
stylesheet), so keep those two together if you move files around.

## A note on 10 to 16

These use made up products, brands, and people since the assignments didn't specify real
ones. The goal with each was to give it its own look, its own colors and fonts, rather than
reusing one template seven times, so don't expect them to match each other visually.

## Practicals 17 to 20 — bigger multi-page projects

These are folders, not single files, since each one is a small multi-page site rather than a
one-pager. Open the index/main file in each folder in a browser; the other pages link to each
other from the nav, so you don't need to open them one by one.

| Folder | Topic |
|---|---|
| practical17/ | 5 page bookstore site (Chapter & Verse), shared header/footer/nav with active state, table, lists, images, responsive nav that collapses to a hamburger menu on mobile |
| practical18/ | Single page admin dashboard (Pulse), sidebar + topbar layout, stat cards, a data table, hover states, no framework used |
| practical19/ | Single page e-commerce product detail page (Aro lounge chair), image gallery, pricing, features, reviews, related products, add to cart / buy now buttons with hover animation |
| practical20/ | 7 page college website (Ashford Institute of Technology): home, about, courses, faculty, gallery, admission form, contact form, all sharing one stylesheet |

practical17/ starts at `index.html`, practical20/ starts at `index.html`, practical18/ is just
`dashboard.html`, and practical19/ is just `product.html`.
