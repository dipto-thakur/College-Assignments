My Favorite Programming Languages

Over the years I've tried out a bunch of programming languages, and each one has its own strengths depending on what you're building. Below I have listed a few of them along with some places to learn more about each.

Ordered List - Ranked by preference

  1. Python, great for beginners and data work, docs at python.org
  2. JavaScript, runs in every browser, reference at MDN
  3. Java, used a lot in enterprise applications

Unordered List - Other languages worth knowing

  • C++, good for performance heavy applications
  • Go, simple syntax and built for concurrency, more at go.dev
  • Rust, known for memory safety without a garbage collector
