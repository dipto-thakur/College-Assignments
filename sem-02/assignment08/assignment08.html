Types of CSS

There are three ways to add CSS to a page. Inline CSS is written directly inside an element's style attribute and only affects that one element. Internal CSS is written inside a style tag in the head of the document and applies to the whole page it's placed in. External CSS lives in a separate .css file and can be linked to any number of pages, which makes it the easiest to reuse and maintain.
