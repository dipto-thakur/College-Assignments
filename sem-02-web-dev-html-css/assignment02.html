HTML is the standard language used to build web pages. It has a lot of built in features that make it flexible and easy to structure content with.

Below are two lists, one ordered and one unordered, each describing a different feature of HTML along with some helpful links to learn more.

Ordered List - Features of HTML

  1. HTML allows embedding of images using the img tag
  2. HTML supports tables for displaying tabular data
  3. HTML lets you add hyperlinks so users can jump to other pages, learn more at MDN Web Docs

Unordered List - Features of HTML

  • HTML has form elements like input, checkbox, and radio buttons
  • HTML supports semantic tags like header, footer, and article
  • HTML can include audio and video directly with the audio and video tags
  • HTML works together with CSS to style content, more info on W3Schools
  • HTML documents can be linked together using anchor tags to build a website
